# Archived pre-public Sessions releases

These tags preserve the signed installer, CLI, updater, and Windows preview
download URLs published before Sessions established its clean public-source
boundary on July 29, 2026.

The original pre-public Git history contained internal product memory and was
moved into a private archive. For that reason, these archived binary tags do not
pretend that today's public source tree is the exact source snapshot used to
build an older binary.

Current public source begins on `main` at commit
`5be12fb0c37887785a1c8bc2a3e9fe1a66a68a1b`. Releases after this history reset
will again use normal source tags whose tree matches the corresponding build.
